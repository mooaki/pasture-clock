# 放牧時計

4つの牧草地にいる牛の頭数で、端末のローカル時刻を表す小さなブラウザアプリです。左から時の十の位、時の一の位、分の十の位、分の一の位です。各区画は牧草地の濃淡で区別します。数字や時刻の文字は画面には表示しません。`cow1.png` と `cow2.png` を1秒ごとに切り替え、牛はゆっくり牧草地を歩き続けます。時刻が変わって頭数が増減すると、牛は区画間を歩いて移動します。移動先がない余剰牛は牧草地の外へ出て、足りない牛は外から入ります。

## 実行

`index.html` をブラウザで開くだけで動きます。ローカルサーバーを使う場合は、このフォルダーで `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開きます。

## GitHub Pages

`index.html`、`style.css`、`script.js` と画像の `cow1.png`、`cow2.png` をリポジトリのルートに置き、GitHub リポジトリの **Settings → Pages** でデプロイ元に `Deploy from a branch`、ブランチと `/ (root)` を選んで保存します。公開後は Pages の URL からアクセスできます。
